# yoankrastev.com

Personal essay site built with [Astro](https://astro.build).

```sh
npm install
npm run dev      # local preview at http://localhost:4321
npm run build    # production build into dist/
```

To publish an essay, add a markdown file to `src/content/essays/`. See [AGENTS.md](AGENTS.md) for the frontmatter, the file structure, how to change the palette, and the design rules.
